Vendored webfonts (latin subset) for the UI type system.

Manrope  - (c) Manrope contributors, SIL Open Font License 1.1 - https://fonts.google.com/specimen/Manrope
IBM Plex Mono - (c) IBM Corp., SIL Open Font License 1.1 - https://fonts.google.com/specimen/IBM+Plex+Mono

Files are the latin-subset woff2 builds published by Google Fonts (variable weight 400-500 for
Manrope, static 400 and 500 for IBM Plex Mono). They are served from this folder instead of a font
CDN so a self-hosted instance renders identically with no outbound network access.

Only weights 400 and 500 are used anywhere in the UI.
